Eka Scribe Widget Demo

This is a demo page for the Eka Scribe floating panel widget. The widget appears in the bottom-right corner and allows you to record audio for medical transcription.

Configuration

Usage

// Method 1: Script tag <script src="scribe-widget.umd.js"></script> <script> const widget = EkaScribe.init({ apiKey: 'your-api-key', baseUrl: 'https://api.example.com', templates: ['soap'], debug: true, onResult: (result) => { console.log('Result:', result); } }); </script> // Method 2: ES Module import EkaScribe from 'eka-scribe-widget'; const widget = EkaScribe.init({ apiKey: 'your-api-key', baseUrl: 'https://api.example.com', });
